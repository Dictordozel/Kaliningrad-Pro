# Контекст проекта (`glitch`)

Обновлено: 2026-05-22

## 1) Цель
Одностраничное статическое демо на Alpine.js с периодическими эффектами текстового глитча для элементов по `id`.

## 2) Структура рабочей папки
- `index.html` - основная страница, стили и вся логика глитча в inline-скрипте.
- `alpine.js` - локальный рантайм Alpine.
- `browser@4.js` - браузерный рантайм Tailwind.
- `fonts/` - локальные шрифты (`Skolar`, `UbuntuMono` и т.д.).

## 3) Текущая структура UI (`index.html`)
Внутри `body`:
- Секция 1: `h1#title-1` (крупный заголовок)
- Секция 2: `p#sub-1`, `p#sub-2`
- Секция 3: `h2#title-2` на светлом фоне

## 4) Текущее устройство движка глитча
Точка входа: `getData()` (Alpine `x-data`).

Состояние:
- `defaultGlitchCharset` - резервный набор символов для случайной подмены.
- `defaultIntensity` - резервная интенсивность (0..1).
- `glitchItems` - конфиг для каждого элемента по `id`.
- `instances` - реестр во время выполнения:
  - `id`, `el`, `config`, `originalText`
  - `startTimeoutId`, `restoreTimeoutId`

Жизненный цикл:
1. `init()`
   - проходит по `glitchItems`
   - находит элемент по `id`
   - сохраняет исходный текст
   - нормализует конфиг
   - запускает независимый таймер для каждого элемента
2. `scheduleGlitch(id)`
   - планирует следующее срабатывание со случайной задержкой в диапазоне `[minDelay, maxDelay]`
3. `runGlitch(id)`
   - если `mode === 'alt'`: ставит случайный альтернативный текст
   - если `mode === 'random'`: искажает символы на основе `charset` и `intensity`
   - возвращает исходный текст через `glitchDuration`
   - планирует следующий цикл
4. `destroy()`
   - очищает таймеры и возвращает исходный текст

## 5) Контракт конфига элемента (`glitchItems`)
Общие поля:
- `mode`: `"random"` или `"alt"`
- `minDelay`, `maxDelay` (мс)
- `glitchDuration` (мс)

Поля для режима `random`:
- `intensity` (0..1, с ограничением диапазона)
- `glitchCharset` (символы для подмены)

Поля для режима `alt`:
- `altTexts` (массив альтернативных строк)
- опционально `altText` как fallback

Примечания:
- В режиме `random` длина результата равна длине исходного текста.
- В режиме `alt` длина результата может отличаться (зависит от выбранной альтернативы).

## 6) Известные нюансы / заметки по чистке
- В CSS подключается `fonts/bebasneuecyrillic.ttf`; убедиться, что файл реально существует в `fonts/`.
- IDE может показывать предупреждения вида `x-data is not allowed here` / `Unused function getData` (обычно это шум статического анализа для Alpine в HTML).
- Если вручную оставить в `glitchItems` поля, не относящиеся к конкретному `mode`, `normalizeConfig()` безопасно их игнорирует.

## 7) Как обновлять этот файл контекста
При изменениях поведения обновляйте разделы:
1. **Текущая структура UI** (если менялись DOM-элементы/`id`/секции)
2. **Текущее устройство движка глитча** (если менялись функции/жизненный цикл)
3. **Контракт конфига** (если добавились/удалились поля или режимы)
4. **Известные нюансы** (новые предупреждения, отсутствующие ресурсы, особенности)

Рекомендуется вести мини-историю изменений внизу.
